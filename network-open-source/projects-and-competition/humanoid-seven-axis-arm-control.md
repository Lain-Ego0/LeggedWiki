# 工程机器人整车研发与七轴双臂实车控制

> 类型：竞赛方案 / 工程机器人 / 机械设计 / 嵌入式与运动控制 / 工程视觉

## 项目简介

该项目整理了一整套工程机器人赛季研发资料，覆盖单臂与双臂工程机器人的机械设计、自定义控制器、仿人形七轴双臂嵌入式控制、工程视觉，以及从方案设计到国赛落地的整车技术报告。

资料中既有 SW 图纸、技术报告、功能及实车展示，也包含核心代码、开发过程中的问题记录和方案取舍，适合作为工程机器人整车研发和七轴机械臂实车部署的参考。

## 资料总览

### 工程机器人机械

分区赛和国赛共四台单臂/双臂工程机器人上台阶，资料包含技术报告、功能展示和完整图纸。

- [工程机器人机械设计、图纸与实车展示](https://bbs.robomaster.com/article/1942225?source=1)

### 自定义控制器机械

资料覆盖六轴单臂控制器和双臂七轴同构控制器，包括完整模型、关节设计和便携收纳方案。

- [自定义单臂/双臂控制器机械设计](https://bbs.robomaster.com/article/1942228?source=1)

### 嵌入式与运动控制

仿人形七轴双臂实车控制方案包括：

- 分层控制架构；
- 7 轴机械臂的 SEW 冗余逆解；
- 加权 DLS（阻尼最小二乘）与 AdaptiveHybrid 调度；
- 全方向重力补偿；
- 部分实车控制核心代码。

- [仿人形七轴双臂实车控制方案](https://bbs.robomaster.com/article/1941628?source=1)

### 工程视觉

工程视觉资料开源了点云配准和“关键点 + PnP”两条技术路线，记录了代码、方案选型过程、踩坑经验和国赛实战情况。

- [工程视觉：点云配准与关键点 + PnP](https://bbs.robomaster.com/article/1940784?source=1)

### RM2026 整车技术报告

整车报告汇总机械、控制、硬件和视觉方向，记录工程机器人从方案设计、反复迭代到国赛落地的完整研发过程。

- [RM2026 工程机器人整车技术报告](https://bbs.robomaster.com/article/1942648?source=1)

## 阅读建议

建议先阅读整车技术报告了解系统背景，再按机械、控制器、运动控制和视觉方向查阅专题资料。具体图纸、代码版本和实车效果以论坛原帖及其后续更新为准。
