# RC_WheelLeg：轮足机器人全开源项目

> 类型：轮足机器人 / ROS 2 / 强化学习 / 实车项目

## 项目简介

RC_WheelLeg 是山东华宇工学院 HYNova 战队开源的轮足机器人项目。团队参加仿生足式障碍赛，最终获得全国一等奖（第 7 名），项目目标是逐步公开机械、硬件、软件、BOM、装配和工程注意事项。

机器人为 **16 自由度串联轮足结构**：每条腿包含 3 个腿部关节和 1 个轮驱动。仓库还公开了面向比赛部署的工程资料，以及从强化学习训练、MuJoCo 仿真、Sim2Sim 到真机部署的完整链路。当前资料并非一次性全部整理完毕，阅读时应结合分支、Tag 和目录中的说明判断具体版本。

项目仓库：

- [zeitvex/RC_WheelLeg](https://github.com/zeitvex/RC_WheelLeg)

## 当前版本

当前发布版本为 **V0.3.8**，主要整理 ROS 2 最终部署内容。

仓库说明中，`v0.3.8` 对应最终比赛 ROS 2 真机工程；`main` 主要对应 16DOF 版本，另有 8DOF 相关分支或历史内容。硬件侧可看到 Jetson Orin Nano 8G、RS02 执行器等信息，具体器件和装配关系仍应以仓库 BOM 与 CAD 文件为准。

仓库目前包含的内容包括：

- 中期 8 自由度版本的机械与软件；
- 纯 A 板下位机方案；
- 部分工程文档与注意事项；
- 早期 16 自由度轮足机器人从训练、仿真到实机的强化学习链路。

目录覆盖机械 CAD/STEP、硬件与固件、训练、仿真、部署、导航和视频等内容；其中部分文件仍处于持续整理状态。

其他完整资料仍在持续整理中。历史版本可以根据仓库 Tag 自行回退和下载。
