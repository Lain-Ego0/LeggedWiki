# M20 DreamWaQ：盲爬高台实验

> 类型：轮足机器人 / DreamWaQ / 高台攀爬 / Isaac Gym

## 项目简介

该项目基于 [Dreamwaq](https://github.com/yusongmin1/Dreamwaq) 框架，在山猫 M20 上进行不依赖视觉输入的高台攀爬实验。投稿者从此前的楼梯模型继续训练，没有修改奖励函数，并在高台任务上加入难度课程。

## 训练设置

投稿记录中的高台高度设置为：

`0.2 + 0.8 × difficulty`

难度分为 40 级。高台训练的平移速度指令设置为 0，因为横向接近高台时机器人难以上去。实验中 75 cm 高台成功率较高，90 cm 高台通常需要前向速度达到约 0.8 m/s 以上；爬上高台后仍存在偏航角较大的问题，需要继续调整。

## 框架能力

Dreamwaq 仓库面向轮足机器人的强化学习，支持仿真训练、MuJoCo Sim2Sim 和实物部署，覆盖 Go2、Go2W、M20、B2W 等平台。仓库中提供 `m20` 任务、地形配置以及 MuJoCo 验证脚本。

其方法重点是从历史本体观测中学习隐式地形表示，并结合速度控制完成复杂地形运动。高台实验沿用了已有模型，因此更适合作为课程迁移和任务增量训练的案例，而不是一套从零开始的独立奖励设计。

## 当前问题

仓库说明中提到，上高台动作仍然偏剧烈，下高台时后腿容易卡住，零速度时还存在轮子偏移等问题。投稿者也记录了爬台后的偏航误差，后续可从速度、关节速度终止条件、偏航惩罚和下台动作等方向继续改进。
