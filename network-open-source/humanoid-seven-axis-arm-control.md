# 七轴双臂人形机械臂实车控制方案

> 类型：实车控制方案分享

## 项目简介

该项目整理了一套仿人形七轴双臂机械臂的实车控制方案，面向冗余机械臂控制与实际部署场景。

## 方案内容

目前分享的内容包括：

- SEW 冗余逆解；
- 加权 DLS（阻尼最小二乘）方法；
- 全方向重力补偿；
- 分层控制架构；
- 部分实车控制核心代码。

该项目目前以论坛帖子和交流为主要入口，建议结合原帖了解完整方案、实现背景和后续更新。
